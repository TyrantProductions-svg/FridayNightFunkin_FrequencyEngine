# Shared props

`voidRumble.png` and `voidRumble.xml` are the reusable Void Rumble DJ-set atlas.
Use `props/voidRumble` as its asset path for title-screen or gameplay props; its
animation frame prefix is `voidRumble`.

The supplied PNG is 828x768, so the XML frame rectangles are scaled to fit it.
If replacing the PNG with a larger export, update the XML coordinates to match.
